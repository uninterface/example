# Uninterface example

Uninterface example is a standalone Vue/Vite app. Its first example is an expense record editor with validation, save and retry.

## Run it

Use Node.js 24 and npm. From this repository's root:

```sh
npm ci
npm run dev
```

Open the local URL printed by Vite.

The `@uninterface/backend` alias in [package.json](package.json) selects the backend. [Change the alias target](docs/setup.md) to use a different backend.
